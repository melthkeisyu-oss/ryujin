# NPO法人○○ AI社員組織図

障害福祉サービスを運営するNPO法人向けの「AI社員10人」の組織図と、各AI社員の職務内容（指示文）です。

- `index.html` … 組織図と職務内容のページ（職務内容はボタンでコピーできます）
- `instructions/` … 各AI社員の職務内容。Claude のプロジェクトの「指示」欄、または Claude Code の経営デモ（`management_demo/各役職/CLAUDE.md`）に貼り付けて使います
- `build.py` / `template.html` … 上の2つを作るためのファイル。職務内容を直したら `python3 build.py` で作り直します

法人名は「○○」になっています。`build.py` の `ORG` を書き換えて作り直してください。
