AI社員
主な仕事
使うAI／効果
    ① 個人情報は仮名で利用者さん・ご家族・職員の実名や病名は入れない。「Aさん」に置き換える。
    ② AIの答えは下書き最後は必ず人が確認してから使う。計画の決定はサビ管、お金は理事長。
    ③ 基準は根拠を確認報酬・加算・運営基準は、最新の告示・通知で確かめてから使う。

    AI社員の職務内容（コピーして使う）

    各AI社員の「職務内容」です。Claude のプロジェクトに貼り付けると、その役職として動きます。10人それぞれに1つずつプロジェクトを作ってください。

    1. Claude を開き、左のメニューから「プロジェクト」を選ぶ英語表示の場合は「Projects」
    2. 「新しいプロジェクト」を作り、名前を「AI CFO」のように役職名にする英語表示の場合は「Create project」
    3. 下の「コピー」を押し、プロジェクトの「指示」欄に貼り付けて保存する英語表示の場合は「Instructions」。Claude Code の経営デモでは、各役職フォルダの CLAUDE.md に貼り付けます
    4. そのAI社員が使う資料（過去の議事録、収支表など）をプロジェクトに入れる個人名は仮名にしてから入れてください
