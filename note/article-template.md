# note 記事テンプレート

コピーして使う。埋まらない項目があるなら、まだ書くネタが煮詰まっていないサイン。

---

## 0. 書く前に1行で決める（記事には載せない）

- **この記事を読んだ人ができるようになること**:
- **想定読者（1人だけ思い浮かべる）**:
- **自分にしか書けない部分（一次情報）**:

> この3行が埋まらない記事は書かない。「AIについて」のような広いテーマは、
> ここが埋まらないので必ず薄くなる。

---

## 1. タイトル

型の例（数字・固有名詞・変化を入れる）:

- `〇〇したら△△が□分→□分になった話`
- `〇〇で3回失敗して、4回目にうまくいった理由`
- `【初心者向け】〇〇を△△するいちばん簡単な方法`

NG: `AIについて考えたこと` / `最近やっていること`

---

## 2. 導入（100〜200字 / 挨拶は書かない）

1行目から結論と読者メリット。

```
〇〇に△△時間かかっていたのが、□□を使って××分になりました。
同じことで困っている人向けに、実際の手順とハマったところを全部書きます。
```

---

## 3. 課題（なぜやろうと思ったか）

- 具体的な状況を数字つきで
- 「面倒だった」ではなく「毎週金曜に40分かかっていた」

## 4. やったこと（最初の試み）

- 実際のコマンド / 設定 / プロンプトをそのまま載せる

## 5. うまくいかなかったこと ← ここが記事の価値

- 出たエラー、想定と違った出力、遠回りした判断
- ここを省くと一気に「よくある紹介記事」になる

## 6. どう解決したか

- 直した内容と、なぜそれで直るのか

## 7. 結果（ビフォー / アフター）

| | Before | After |
|---|---|---|
| 時間 | | |
| 手間 | | |

## 8. 学び・次にやること

- 3行以内。長い総括は読まれない。

## 9. 締め（スキ・コメント導線）

```
同じような使い方をしている方、もっといいやり方があればコメントで教えてください。
参考になったらスキをもらえると次を書く励みになります。
```

---

## 10. 公開設定

- ハッシュタグ: 3〜5個（広いタグ1つ + 具体的なタグ2〜4個）
- 見出し画像: 文字入りで内容が一目で分かるもの
- 関連する公式マガジンがあれば投稿
