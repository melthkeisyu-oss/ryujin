# 定期ルーティン用プロンプト

claude.ai の Routines(定期実行)に貼り付けて使うプロンプトの保管場所。
ルーティンを直接編集すると差分が追えなくなるため、**ここを正本**とし、
変更したらルーティン側に貼り替える運用にする。

| ファイル | 対応するルーティン | 実行時刻 |
|---|---|---|
| `daily-sns-keisyu.md` | 毎日のSNS下書き(田中圭周) | 毎日 07:00 JST |
| `daily-bistargo.md` | BISTARGO COFFEE 毎日のnote+Threads下書き | 毎日 08:00 JST |

## 貼り替え手順

1. claude.ai を開く → Routines(定期実行)一覧
2. 対象のルーティンを開き、プロンプト欄を**全選択して削除**
3. 上記ファイルの中身を**全文コピーして貼り付け**、保存

## 設計の考え方（2026-08-21 改訂）

### 質とスキは別の回路

- **情報の濃さ** → 信頼・検索流入・保存 を作る
- **感情の共感** → スキ・フォロー を作る

制度・表・FAQ を積み上げるほど記事は「よくできたマニュアル」に近づき、
むしろスキは押されにくくなる。両方を取るために、**曜日で型を切り替える**。

| 型 | 曜日(JST) | 字数 | 見出し | 狙い |
|---|---|---|---|---|
| 型A 共感型／物語型 | 月・水・木・土・日（週5） | 1,800〜2,600字 | 4〜5個 | スキ・フォロー |
| 型B 情報型／実用型 | 火・金（週2） | 2,500〜3,500字 | 5〜7個 | 検索流入・保存 |

週5:2で共感型に寄せているのは、スキを増やすことが現在の最優先だから。
検索流入を優先したくなったら、この比率を 4:3 や 3:4 に変えるだけでよい。

### 全記事に共通する「スキ設計」

1. **冒頭3行**をセリフか情景で始める（noteのタイムラインには冒頭数行しか出ない）
2. **読者の心の声**を鉤括弧でそのまま書く（「自分のことだ」のスイッチ）
3. **書き手の弱さ・迷い・失敗**を1つ開示する
4. **現場のワンシーン**を会話つきで（＋事例再構成の注記）
5. **一文40字以内・一段落3文以内**（スマホ前提）
6. **見出しは20字以内**、問いか意外性の形に
7. **説教しない**（「〜すべき」「〜が大切です」で終わる段落を作らない）
8. **締めの最後は読者への肯定・ねぎらい**、その直後に具体的な問いを1行

### メールに追加した2ブロック

- **セルフチェック** … 上記を満たしたか✓/×で自己申告。×なら修正してから送信
- **投稿後の3アクション** … スキは記事の外でも作られる。同テーマの新着に
  スキ・コメント、前日コメントへの返信、その日の記事に応じた提案

## 事実関係の扱い（重要）

制度名・統計・金額・産地情報など、**確信が持てない数値や固有情報は書かせない**
方針をプロンプトに明記している。生成物を公開する前に、数字が入っている箇所は
必ず一次情報（厚労省・自治体・焙煎業者の仕様書など）で裏取りすること。
