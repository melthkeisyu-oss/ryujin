# 定期ルーティン用プロンプト

claude.ai の Routines(定期実行)に貼り付けて使うプロンプトの保管場所。
ルーティンを直接編集すると差分が追えなくなるため、**ここを正本**とし、
変更したらルーティン側に貼り替える運用にする。

| ファイル | 対応するルーティン | 実行時刻 |
|---|---|---|
| `daily-sns-keisyu.md` | 毎日のSNS下書き(田中圭周) | 毎日 07:00 JST |
| `daily-bistargo.md` | BISTARGO COFFEE 毎日のnote+Threads下書き | 毎日 08:00 JST |

## 貼り替え手順

1. claude.ai を開く → Routines(定期実行)一覧
2. 対象のルーティンを開き、プロンプト欄を**全選択して削除**
3. 上記ファイルの中身を**全文コピーして貼り付け**、保存

## 2026-08-21 の改訂内容

記事が短く・薄く、note のスキが伸びない問題への対策。

- 本文の下限を 1500字 → **2500字**(上限3500字)に引き上げ
- 見出しを 2〜3個 → **5〜7個**に増やし、抽象的な見出しを禁止
- **濃さの必須要素7項目**を新設(現場のワンシーン+会話、制度・統計への具体的言及、
  表、今日からできる3つのこと、限界への言及、一次情報が半分以上 など)
- **薄くなる書き方を明示的に禁止**(挨拶・前置き、「〜かもしれません」の多用、
  定義説明だけの見出し、「大切です」で終わる段落)
- Threads の1行目を「具体的な事実・数字・セリフ」始まりに固定
- **送信前セルフチェック**をメールに必ず添付させ、×が残る場合は修正してから送信
- BISTARGO 側は淹れ方レシピの数値化・味の3段階描写・FAQ を必須要素に追加、
  テーマの連日重複(ちゅらそら偏り)を防ぐルールを追加

## 事実関係の扱い(重要)

制度名・統計・金額・産地情報など、**確信が持てない数値や固有情報は書かせない**
方針をプロンプトに明記している。生成物を公開する前に、数字が入っている箇所は
必ず一次情報(厚労省・自治体・焙煎業者の仕様書など)で裏取りすること。
