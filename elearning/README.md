# 法定研修 eラーニング（NPO法人琉仁福祉会）

障害福祉サービス事業所の法定研修（虐待防止・身体拘束等の適正化・感染症・BCP）を、
**台本（文字）から、字幕と読み上げ音声つきの約10分の動画と、確認テストつきの受講ページ**として自動で作る仕組みです。

## フォルダ
| 場所 | 中身 |
|---|---|
| `facts/<年度>.json` | その年度の数字（虐待の統計など）と年度名。**毎年まずここを直す** |
| `content/<年度>/*.json` | 台本。翌年度は「前年度の台本＋変更点」だけを書く（`base` と `slide_ops`） |
| `build.py` | 生成プログラム |
| `dist/<年度>/` | できあがり（`*.mp4` と `index.html`） |
| `UPDATE.md` | 毎年の作り直し手順 |

## 作り方
```
pip install pyopenjtalk-plus pillow numpy   # 初回だけ（読み上げ音声のエンジン）
python build.py R9 --dry                    # 台本の文字数と予想時間だけ確認
python build.py R9                          # 4本の動画と受講ページを作る
python build.py R9 01_gyakutai              # 1本だけ作り直す
```
ffmpeg と日本語フォント（IPAゴシック）が必要です。

## 台本の書き方
- `slides[].say`：読み上げる文。1文ずつ字幕になる（1文は100字くらいまで）
- `slides[].bullets`：画面の箇条書き。先頭に `!` を付けると強調
- `slides[].table`：表（1行目が見出し）
- `{{abuse_reports}}` のような書き方で、`facts` の数字を差し込める
- 読み方を直したい言葉は `build.py` の `READINGS` に足す（例：BCP → ビーシーピー）

## 受講記録
受講ページで氏名と事業所を入れ、確認テストで8割以上正解すると修了。
「記録をダウンロード（CSV）」か「管理者にメールで送る」で記録を集める。
送り先は `facts/<年度>.json` の `report_to` にメールアドレスを入れる。
